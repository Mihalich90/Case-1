Разбор алгоритма
Находим индексы максимального и минимального элементов (index() возвращает первое вхождение).

Определяем границы left и right — так, чтобы left < right (порядок не важен, важно «между»).

Проходим по срезу arr[left+1 : right] (строго между, без самих границ).

Складываем только отрицательные элементы (x < 0).
